# Do'kondagi printerlar

Foydalanuvchi tasdiqlagan vazifalar (2026-11-01):

| Qurilma | Vazifasi | Windows nomi | Hozirgi USB porti | Drayver |
|---|---|---|---|---|
| XP-80U | Server kompyuteridagi xarid cheki | Xprinter XP-80 | USB001 | Xprinter XP-80 |
| XP-80T | Ikkinchi kassadagi xarid cheki | Xprinter XP-80T | USB002 | Xprinter XP-80 |
| XP-365B | Ish boshlanishida shtrix kod yorliqlarini chiqarish | Xprinter XP-365B | USB003 | Xprinter XP-D365B |

XP-80U foydalanuvchi tasdig'iga ko'ra ishlayapti; uning sozlamasi o'zgartirilmasin.
XP-80T ga yorliq drayverini, XP-365B ga chek drayverini biriktirmang.
Portlar hozir serverga ulangan holat uchun. Boshqa kompyuterda USB raqami farq qilishi mumkin.
XP-365B kundalik xarid cheklari uchun tanlanmasin.
